# Disease Prediction System

A simple and efficient **Disease Prediction System** that analyzes user-provided symptoms and predicts possible diseases using data-driven and machine learning techniques. This project demonstrates how AI can be applied in healthcare for quick insights.

---

## Features
- Predicts diseases based on symptoms  
- Simple and user-friendly interface  
- Fast and efficient predictions  
- Built using basic machine learning concepts  
- Useful for learning and academic projects  

---

## 🛠️ Tech Stack
- Python  
- Pandas  
- NumPy  
- Scikit-learn  

---
## API
- https://disease-api-rf30.onrender.com/

## How It Works
1. User inputs symptoms  
2. System processes the input  
3. Trained model predicts disease  
4. Results are displayed
